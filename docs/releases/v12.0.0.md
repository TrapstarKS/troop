# troop v12.0.0

The first release of the personal-use [troop fork](https://github.com/TrapstarKS/troop),
based on [NOOP](https://github.com/ryanbr/noop) 12.0.0. It combines the fork's changes since the
shared `c800fb619` baseline with the applicable upstream changes through `8e94d559b`.
It remains an independent, unofficial, non-commercial companion: no account, server or telemetry;
strap data and analytics stay on-device.

## Pulled from upstream

- **Charge consistency:** the breakdown uses the headline's baselines, with an explicit rule for
  eligible nights and a regression case for long gaps in recorded data.
- **Apple performance:** live Effort scoring leaves the main actor; Trends windows and chart styles
  are reused; chart inspection uses date-ordered lookups; panel compositing, motion and idle redraws
  are reduced. HealthKit observer imports stay within the recent sync window.
- **Russian localization:** grammatical plurals cover sleep, workouts, Journal, Charge, body-age
  counts, battery accessibility, charts, imports and Watch countdowns.
- **Shortcuts and workouts:** recorded routes can be exported as GPX or FIT, with an explanation of
  FIT's limits. Android gains improved workout heart-rate charts and detail layout. Today's live
  workout controls reuse the existing session actions where that upstream surface is retained.
- **Readouts and diagnostics:** session availability, sleep movement scale, saved-workout exclusion
  and Health water import are explained; ended iOS heart-rate banners are removed; workout overlap
  and sustained-effort diagnostics gain useful context.
- **Release plumbing:** Apple CI coverage guidance is corrected, and the iOS product name is NOOP.
  Fork identifiers and the future private-key Android signing boundary are kept. This release is
  published locally with verified assets because the complete stable workflow requires that key.

The fork already carried fixes for history repair before recent rescoring, Apple Health heart-rate
source export/write authorization and Android Material accent handling; this update preserves them.

## troop highlights since the shared baseline

- **Four-tab navigation:** Home, Health, Plan and More, a dark default theme, and a floating Coach
  sheet with coordinated activity and detail navigation.
- **Home:** Sleep / Recovery / Strain dials, selected-day stepping, daily guidance, Health Monitor
  and Stress tiles, My Day activity actions, weekly progress and dashboard hide/reorder controls.
- **Recovery, Strain and activities:** day-specific details and charts, activity editing or editing
  a copy, and a 0–21 Strain axis. This is a lossless display mapping of local Effort, not WHOOP's model.
- **Sleep:** selected-night stages and heart rate, naps and history, missing fragment gaps, recorded
  duration labels, Sleep Planner goals, wind-down reminders and haptic alarm scheduling.
- **Health:** a five-row Health Monitor, local wellness alerts, 30/180-day Health Report PDFs,
  Healthspan and Stress Monitor details, VO₂ Max and Steps cards. Source ownership, freshness and
  unavailable readings are carried through to the displayed values.
- **Plan:** Journal, Behavior Insights, Weekly Plan, calendar-aware Trends and Monthly Performance;
  drafts remain attached to the date or week they were opened for.
- **More and local notifications:** grouped settings and notification history, with Coach, weekly
  plan and battery reminders opening the relevant screen.
- **Firmware guidance:** reported strap versions and an isolated Experimental simulation. The
  simulation uses mocks and never flashes a strap.
- **Install preparation:** separate fork identities, safeguards for a future private-key Android
  channel, user re-signing for iOS, checksum/signature metadata and a fork-only Classic source format.

## Downloads and migration

**The stable privately signed Android APK is not included in this release: no private signing key
was provided.** No new signing keys or repository secrets were created.

- `NOOP-android-public-testing-key-v12.0.0.apk`: Full testing build, package
  `com.trapstarks.troop.staging`, version **12.0.0-staging**, versionCode **551**. It is signed with
  the public testing key committed in the repository. That key does not establish a private
  publisher identity; this APK is outside the stable Android channel. It installs beside upstream
  NOOP and stable troop. Demo and debug APKs are not included.
- `NOOP-macos-v12.0.0.zip`: Release app for Intel and Apple Silicon, ad-hoc signed and not notarized;
  bundle `com.trapstarks.troop.noop.staging`, app name **NOOP Staging**, build **199**.
- `NOOP-ios-unsigned-v12.0.0.ipa`: device Release build for user provisioning through SideStore,
  AltStore Classic or Sideloadly; bundle `com.trapstarks.troop.noop`, app name **NOOP**, build **432**.
  The widget extension is retained with replaceable capability templates; the Watch app is excluded.
- `NOOP-android-public-testing-key-v12.0.0-metadata.json` and `SHA256SUMS`: testing APK
  identity/version/public-signer metadata and checksums for all four artifacts.

Follow [the fork installation guide](https://github.com/TrapstarKS/troop/blob/main/docs/INSTALL.md).
Export `.noopbak` before migration, uninstalling, or changing signing identities, accounts or
sideloaders. The default iOS identity is separate from upstream; an update replaces the same
provisioned fork app. Provisioning determines access to HealthKit, widgets and Live Activities.
Verify the downloaded IPA before re-signing it, which changes its bytes.

## Validation and limits

The merged source passed xcstrings JSON/duplicate-key validation, Android resource validation and
XcodeGen generation. Local unsigned Release builds passed for macOS (Intel and Apple Silicon) and
generic iOS devices using Xcode 26.6 with two jobs. Android compilation passed; the en_US JVM suite
ran 6,913 tests: 6,905 passed, six were skipped and the two known RecoveryDrivers rounding baseline
failures remained. No new build or test failure was found. No real phone or strap validation is
claimed. Installation, data-preserving upgrades, BLE sync, alarms and Apple Health
writes still need physical-device checks. WHOOP 5/MG historical offload remains unresolved;
live heart rate does not establish working history. Oura support remains Experimental.

This fork makes no continuing release/support promise and is not a medical device.
